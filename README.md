# CSE594 — Human–AI Interaction

Course code for Fall 2026.

| Folder | Project | Running instructions |
|---|---|---|
| `Assignment I/` | Tweet emotion labeling website | [README](Assignment%20I/README.md) |
| `Assignment II/` | Facial expression classification, model evaluation, and error analysis | [README](Assignment%20II/README.md) |

Clone the repository:

```bash
git clone https://github.com/ShiyuXu99/CSE594-HAI.git
cd CSE594-HAI
```

Enter the assignment folder and follow its README. Each assignment uses its
own Python environment and requirements file. Assignment I requires a
PostgreSQL database; Assignment II runs locally with the included model
and 200 study images.
